# 상품 이미지 저장기

건강산, 고니B2B, 유픽B2B 상품의 이미지와 정보를 저장하는 Windows용 프로그램입니다.

## 다운로드

[최신 버전 페이지](https://github.com/BritzPro/bbaek-image-extractor-releases/releases/latest)

현재 공개 배포를 준비 중입니다. 첫 배포가 게시되면 위 링크에서 EXE 파일을 받을 수 있습니다.

## 사용 안내

- EXE 파일을 내려받아 Windows에서 실행합니다.
- 사이트 계정 정보는 사용하는 PC의 사용자별 로컬 저장소에 보관합니다. 배포 EXE에 계정 정보가 포함되지 않습니다.
- 실행 시 새 버전이 있으면 업데이트 여부를 묻습니다. 동의하면 다운로드와 적용을 진행합니다.
- 지원 사이트는 건강산, 고니B2B, 유픽B2B입니다. 다른 사이트의 상품 주소는 현재 지원하지 않습니다.
